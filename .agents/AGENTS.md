# Project Rules

## Git Commit Rules
1. Do NOT automatically perform git commits when making code changes.
2. Only run `git commit` when explicitly requested by the user.
3. All git commit messages MUST strictly follow this exact format:

`[MMM DD, YYYY] - Athirathan T : [Commit message]`

Example:
`Jul 31, 2026 - Athirathan T : Updated catalyst function deployment and frontend URL`
